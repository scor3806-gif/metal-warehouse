# Склад металла (локальный)

Простое веб-приложение для учёта металла на распродажу.

Любой, кто открыл сайт, может менять количество, добавлять и удалять позиции.

## Требования

- Windows
- Node.js (скачать с https://nodejs.org — рекомендуется LTS-версия)

## Как запустить

1. Распакуйте папку `metal-warehouse` куда удобно.
2. Откройте командную строку (cmd) или PowerShell **в этой папке**.
   (Можно щёлкнуть правой кнопкой по папке → «Открыть в терминале»)
3. Выполните команду:

```
node server.js
```

4. Откройте в браузере:  
   **http://localhost:3000**

## Как открыть с других компьютеров и телефонов в офисе

1. Узнайте IP-адрес вашего компьютера:
   - Откройте командную строку
   - Введите `ipconfig`
   - Найдите строку **IPv4-адрес** (обычно 192.168.x.x)

2. На других устройствах в браузере откройте:
   ```
   http://ВАШ_IP:3000
   ```
   Например: `http://192.168.1.45:3000`

3. Если не открывается — при первом запуске Windows может спросить разрешение брандмауэра. Нажмите «Разрешить».

## Что можно делать

- Менять количество прямо в таблице (сохраняется сразу)
- Добавлять новые позиции кнопкой «+ Добавить позицию»
- Удалять позиции кнопкой ✕
- Искать по типу, марке, размеру

## Данные

Все данные хранятся в файле `data.json` рядом с `server.js`.  
Можно делать резервные копии этого файла.

## Остановка

В окне командной строки нажмите `Ctrl + C`.
