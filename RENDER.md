# Инструкция по размещению на Render.com

## Важно знать
На бесплатном тарифе:
- Сайт засыпает через 15 минут бездействия
- При пробуждении данные (data.json) могут сброситься
- Первый заход после сна занимает 30–50 секунд

Если данные должны сохраняться всегда — лучше потом взять платный тариф или российский VPS.

## Как задеплоить

### Способ 1 — через GitHub (рекомендуется)

1. Зарегистрируйся на https://github.com (если ещё нет)
2. Создай новый репозиторий (New repository)
3. Загрузи в него всю папку metal-warehouse
4. Зайди на https://dashboard.render.com
5. Нажми **New +** → **Web Service**
6. Подключи свой GitHub-аккаунт и выбери репозиторий
7. Настройки:
   - Name: metal-warehouse (или любое)
   - Runtime: Node
   - Build Command: оставь пустым
   - Start Command: `node server.js`
   - Instance Type: Free
8. Нажми **Create Web Service**

Через 1–2 минуты сайт появится по адресу вида:
https://metal-warehouse-xxxx.onrender.com
